# Планировщик задач

Веб-приложение для разовых и повторяющихся задач. Сервер на Go раздаёт веб-интерфейс и HTTP API, а PostgreSQL хранит расписание.

- Создание, редактирование, удаление и завершение задач
- Поиск по заголовку, комментарию или дате в формате `ДД.ММ.ГГГГ`
- Повторение каждые 1–400 дней или ежегодно. При завершении разовая задача удаляется из списка, а повторяющаяся переносится на следующую дату

Проект использует Go 1.25, `net/http`, `database/sql`, драйвер `pgx` и PostgreSQL 18.

## Запуск

Понадобится Docker с плагином Compose. Все команды выполняются из корня проекта.

1. Скопируйте `.env.example` в `.env`
2. Придумайте пароль для локальной базы и запишите его в `DB_PASSWORD`. При первом запуске PostgreSQL создаст пользователя с этим паролем. При повторном запуске используйте прежний `.env`
3. Запустите приложение командой ниже

```sh
docker compose up --build -d
```

Откройте [http://localhost:7540](http://localhost:7540). Чтобы использовать другой порт, измените `TODO_PORT` в `.env`. Локальный `.env` исключён из Git.

Для остановки выполните `docker compose down`. Задачи сохраняются в томе `todo_postgres_data`.

### Смена пароля базы

Для существующей базы сначала откройте `psql` с текущими настройками.

```sh
docker compose exec postgres psql -U postgres -d scheduler
```

Выполните `\password postgres`, введите новый пароль и выйдите командой `\q`. Затем обновите `DB_PASSWORD` в `.env` и выполните `docker compose up -d`, чтобы приложение подключилось с новым паролем.

## HTTP API

| Метод | Маршрут | Действие |
| --- | --- | --- |
| `GET` | `/api/tasks` | Получить до 50 задач, отсортированных по дате. Параметр `search` ищет по тексту или дате |
| `POST` | `/api/task` | Создать задачу |
| `GET` | `/api/task?id=1` | Получить задачу по ID |
| `PUT` | `/api/task` | Обновить задачу. ID передаётся в поле `id` тела запроса |
| `DELETE` | `/api/task?id=1` | Удалить задачу |
| `POST` | `/api/task/done?id=1` | Отметить задачу выполненной |
| `GET` | `/api/nextdate` | Рассчитать следующую дату по параметрам `date` и `repeat`. Параметр `now` задаёт дату отсчёта |

При создании и обновлении задачи передавайте JSON с обязательным полем `title` и полями `date`, `comment` и `repeat` по необходимости. Дата в API передаётся в формате `ГГГГММДД`. Если дату не указать, сервер подставит сегодняшнюю. Примеры правил повторения — `d 7` для интервала в семь дней и `y` для ежегодного повторения. Пустое правило задаёт разовую задачу.

## Тесты

Для тестов функций и валидации HTTP-запросов понадобится Go 1.25 или новее. Из корня проекта выполните команду ниже

```sh
go test ./...
```

Обычный прогон проверяет расчёт повторений, обработку дат и некорректные запросы на подготовленных данных.

Для проверки работы с PostgreSQL запустите Docker Desktop и выполните интеграционный сценарий создания, чтения, изменения и удаления задачи.

```sh
go test -tags=integration ./tests -count=1
```

Он автоматически запускает временную базу и HTTP-сервер, затем очищает ресурсы. GitHub Actions выполняет оба вида проверок при каждом push.
